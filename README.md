# FaceCheck

[FaceCheck](https://face-check.net) is a reverse face search and photo lookup service that helps you explore where a face may appear across publicly accessible online sources.

Upload a clear photo, adjust the crop, and review possible visual matches with confidence bands and links to the original public pages. FaceCheck is designed to support careful research: every result is a lead to investigate, not proof of identity.

## What FaceCheck offers

- Reverse face search from a single photo
- Possible matches from publicly accessible profiles, posts, and indexed pages
- Visual similarity scores grouped into clear confidence bands
- Direct source links for reviewing names, captions, dates, and context
- No account required and no subscription
- Support for JPG, PNG, and WebP images up to 10 MB

## How it works

1. Choose a clear image with one visible adult face.
2. Center and crop the face for a useful comparison.
3. Run the search with a FaceCheck credit.
4. Review possible matches, confidence bands, and their public sources.
5. Verify each source before drawing any conclusion.

## Common use cases

FaceCheck can help you:

- Review an unfamiliar dating or social profile photo
- Investigate possible photo impersonation
- Explore your own public photo footprint
- Find possible social media appearances from a photo
- Search using a clear face frame captured from a video

## Responsible use

A similar-looking result does not confirm identity, account ownership, or wrongdoing. Always open the linked source, compare the surrounding context, respect applicable laws and platform rules, and use only photos you are entitled to submit.
